How It's Wired

E

Mac Mini → Router

50' Cat6 Ethernet cable, hardwired. Most reliable path for Xcode downloads, agent runs, overnight builds. All other devices stay on the same local network.

W

ThinkBook → Router

Wi-Fi 6E. Your cockpit doesn't need the wire — it's doing browser, GPT, light edits. Stays lightweight.

U

Monitor → Both Machines

HDMI to Mac Mini (primary). USB-C or HDMI to ThinkBook when needed. KVM switch optional for one-keyboard control.

T

Tailscale Mesh

Encrypted overlay network across all three devices. SSH into Mac Mini from ThinkBook or iPhone from anywhere. No port forwarding, no VPN hassle.

The $1,000 Decision — 2-Week Gate

Keep 24GB If these pass

  • Xcode installs cleanly, Big Nate builds to simulator
  • Archive succeeds, TestFlight path is clear
  • One real overnight job runs without bogging down
  • Your primary workload is app builds + light agent work
  • 512GB storage doesn't feel cramped after Xcode + simulators

Upgrade If any of these hit

  • Xcode + Big Nate feels cramped immediately
  • You want serious local AI compute (70B+ models)
  • 512GB fills up after Xcode, simulators, and repos
  • You're running 5+ concurrent agent sessions regularly
  • Budget allows jump to 48GB without stress

Prove the Apple path

Install macOS updates, Xcode, clone Big Nate from GitHub. Build to simulator. Do not customize anything else first. This is the return-window truth test.
