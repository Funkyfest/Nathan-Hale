# Agent skills index

Agents working for Nathan: before starting a task, check whether a skill below
matches the request. If one does, read its `SKILL.md` and follow it in place of
your default approach.

| Skill | Use when | File |
|---|---|---|
| inbox-triage | "triage my inbox", "go through my email", "next 10", an inbox screenshot with no text, "what needs my attention in email" | `inbox-triage/SKILL.md` |
| specificity | Before any question to Nathan: a decision, quiz, yes/no, or choice | `specificity/SKILL.md` |
| skill-harvest | A task Nathan asked for is finished and verified; or a skill run exposed a gap | `skill-harvest/SKILL.md` |
| role-pursuit-kit | Nathan is interviewing with, pitching, or evaluating a firm; needs a follow-up deck | `role-pursuit-kit/SKILL.md` |
| deck-edit | Change, fix, or redact something in an existing HTML deck | `deck-edit/SKILL.md` |
| deck-verify | Before showing, publishing, or committing any HTML deck | `deck-verify/SKILL.md` |
| publish-check | Before any push to a public repo, share link, or send outside Nathan's accounts | `publish-check/SKILL.md` |

## Standing rules for every skill

- End each reply that needs Nathan with choices: the recommendation first, each
  option with a one-line why and a confidence %. Where there is no clickable UI,
  use a numbered list.
- Read-only on outside systems unless the skill says otherwise. Nathan sends,
  pays, signs, and publishes.
- Log decisions and receipts to Open Brain (OB1) when it is connected.
