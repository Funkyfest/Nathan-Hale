# Data Center Design Guide

A comprehensive technical guide covering how modern data centers and AI factories are designed, built, powered, cooled, networked, and operated.

## What's in this directory

| File | Description |
|------|-------------|
| `data-center-design.md` | The document source (Markdown, ~40 pages, 9 parts, 33 chapters, glossary) |
| `build.py` | One-shot script that regenerates all 10 SVG diagrams, an HTML edition, a Word (.docx) edition, and a print-ready PDF |
| `diagrams/*.svg` | 10 original isometric SVG figures (regenerated by `build.py`) |
| `diagrams-png/*.png` | Same figures rasterized for Word / PDF (regenerated by `build.py`) |
| `data-center-design.html` | Standalone HTML with inlined SVGs and dark theme (regenerated) |
| `data-center-design.docx` | Microsoft Word edition (regenerated) |
| `data-center-design.pdf` | Print-ready PDF edition (regenerated) |

## Regenerating all output formats

```bash
# From the repo root
cd docs

# One-time dependencies
apt-get install -y pandoc
pip install cairosvg weasyprint

# Regenerate all diagrams and all output formats
python3 build.py
```

`build.py` produces:

- 10 SVG diagrams in `diagrams/`
- 10 PNG rasterizations in `diagrams-png/`
- `data-center-design.html` — self-contained, dark-themed, all SVGs inlined
- `data-center-design.docx` — via pandoc
- `data-center-design.pdf` — via weasyprint

## What's covered

**Part I — Foundations.** What a data center is, five generations of evolution, campus anatomy.

**Part II — Siting and Civil.** Site selection factors, building shell shapes, construction schedules.

**Part III — The Power Chain.** Utility to chip: substation, MV/LV switchgear, UPS, PDUs, busway, VRMs. Uptime Institute Tier I–IV. Diesel gensets, batteries, fuel cells, SMRs.

**Part IV — Thermal Management.** Air cooling and aisle containment, rear-door heat exchangers, direct-to-chip liquid, immersion. Facility loops, technology loops, CDUs. PUE, WUE, CUE.

**Part V — The White Space.** Slab vs raised floor, rack standards (19", OCP, NVL72), structured fiber cabling.

**Part VI — The Network.** Leaf-spine (Clos), Ethernet vs InfiniBand vs NVLink, rail-optimized fabrics, DCI.

**Part VII — The AI Factory.** Why AI DCs are different, pod architecture, power synchrony, training vs inference, case studies (xAI Colossus, Stargate, Meta Hyperion, Google TPU).

**Part VIII — Safety, Security, Operations.** Physical security, VESDA & pre-action fire, DCIM/BMS/CMMS, L1–L5 commissioning.

**Part IX — The Business and the Future.** Economics, regulation, sustainability, heat reuse, the frontier (SMRs, 1 MW racks, co-packaged optics).

## Reading order

- **Executive** — read the executive summary, Chapter 3 (anatomy), Chapter 30 (economics), Chapter 33 (the frontier).
- **Engineer** — read Parts III, IV, VI, VII cover-to-cover.
- **Curious generalist** — read straight through; every term is defined on first use and again in the glossary.
